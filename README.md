# Quadro de Vagas de Residência Médica — SES/SP

Painel interativo com as vagas de residência médica credenciadas, ofertadas,
ocupadas (2026) e projetadas (2027) por instituição e especialidade na rede
de residência médica do Estado de São Paulo.

Dados extraídos da planilha "Quadro de Vagas SES 2027" (Secretaria de Estado
da Saúde de São Paulo). Nomes de instituições e especialidades foram
normalizados apenas quanto a grafia/caixa; nenhum valor numérico foi alterado.

🔗 Site publicado via GitHub Pages a partir de `index.html`.
